# Arclight brand

The "fast-forward" mark: two rounded chevrons with a blue-to-cyan gradient (`#2f7bff` → `#6ef6ff`), the back chevron at 45% opacity.

| File | Use |
|---|---|
| `mark-color.svg` | Primary mark on dark or light backgrounds |
| `mark-white.svg`, `mark-black.svg` | One-colour versions |
| `app-icon.svg`, `png/app-icon-*.png` | Rounded-square icon on the dark gradient tile (180 = apple-touch-icon, 192/512 = PWA, 1024 = App Store / Play source) |
| `png/mark-16/32/48.png` | Favicons |
| `lockup-dark-bg.svg`, `lockup-light-bg.svg` | Mark with the ARCLIGHT wordmark |

The wordmark is set in Chakra Petch 700 (SIL Open Font License). Convert the text to outlines for print or wherever the font is not loaded.

Colours: background `#02070a` → `#0b1830`, text `#e9fdff`, accent `#6ef6ff`, primary `#2f7bff`.

The startup intro (`intro/`: the 6.1 s animation, its renderer, the rendered MP4s and the sound) uses a different wordmark, "Light Slice" (`intro/wordmark.svg`: Michroma letterforms as outlines, SIL Open Font License 1.1). It is used only in the intro; everywhere else keeps the lockups above, and small places use the mark alone.
