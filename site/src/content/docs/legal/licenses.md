## Arclight is GPL-3.0

Arclight, including the server, the web interface and the mobile apps, is free software under the **GNU General Public License v3.0**.

In short, you may:

- use it for any purpose;
- study it and change it;
- share it;
- share your changed versions, as long as you also license them under the GPL-3.0 and make the source available.

This is a summary, not a replacement for the license. Read the full text: [LICENSE on GitHub](https://github.com/ZacABrewer/arclight/blob/main/LICENSE).

The website documentation is part of the same repository and is covered by the same license unless a file says otherwise.

## Get the source

The full source code is on GitHub: [github.com/ZacABrewer/arclight](https://github.com/ZacABrewer/arclight). If you received a copy of the app and want the matching source, that is where it lives. You can also email `support@moviemethat.com`.

## Third-party components

Arclight includes and depends on open-source components. Each keeps its own license. A list is in [NOTICE.md](https://github.com/ZacABrewer/arclight/blob/main/NOTICE.md) on GitHub, and the apps include a licenses screen.

Arclight is an independent, from-scratch implementation. Other projects' behavior and documentation informed it, but it does not include their source code. See [Attribution and non-affiliation](/legal/attribution/).

## Fonts

The interface uses **Chakra Petch**, licensed under the [SIL Open Font License 1.1](https://openfontlicense.org/). The font is bundled, so no font requests go to third parties. The ARCLIGHT wordmark in the startup intro is drawn from **Michroma** letterforms (also SIL Open Font License 1.1), converted to outlines.

## Name and logo

The Arclight name and logo identify the official project. You are free to use, change and share the code. If you publish a fork or a modified build, please give it **your own name and logo** so people do not mistake it for the official version. Saying that your project is "based on Arclight" or "compatible with Arclight" is fine.
