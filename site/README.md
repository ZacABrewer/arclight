# Arclight website

The public website at https://arclight.moviemethat.com: landing page, the documentation from
[`docs/`](../docs), support and legal pages, with full-text search. Built with
[Astro](https://astro.build) and [Starlight](https://starlight.astro.build), served as static
files by a Cloudflare Worker.

This folder is its own pnpm project (it has its own `pnpm-workspace.yaml` and lockfile) and is
not part of the app workspace in the repository root.

## Run it locally

```sh
cd site
pnpm install
pnpm dev        # http://localhost:4321, rebuilds on change
pnpm build      # production build into dist/
pnpm preview    # serve dist/
pnpm dev:worker # serve dist/ through wrangler, with the real _headers (CSP) and 404 handling
```

Node 24 and pnpm 10 (the version in `packageManager`, via `corepack enable`).

## Where the content comes from

| Content | Source | Notes |
|---|---|---|
| Docs (`/docs/...`) | `../docs/**/*.md` | Copied by `scripts/sync-docs.mjs` into `src/content/docs/docs/` (git-ignored). Never edit the copies. |
| Landing page (`/`) | `src/content/docs/index.mdx` | |
| Support (`/support/`) | `src/content/docs/support.md` | The mobile apps' store "Support URL". |
| Legal (`/legal/...`) | `src/content/docs/legal/*.md` | Privacy policy, terms and the rest. Sidebar group appears when the folder has pages. |
| Logo, favicons, social card | `../design/brand/` | Built by `scripts/brand-assets.mjs` (outputs git-ignored). |

`pnpm dev` and `pnpm build` run both scripts first.

### What `sync-docs.mjs` does

- Takes every `docs/**/*.md` except internal notes (`docs/design/`, `docs/UI-INVENTORY.md`).
  File names become lowercase slugs: `docs/TROUBLESHOOTING.md` is `/docs/troubleshooting/`,
  `docs/README.md` is `/docs/`, `docs/qa/README.md` is `/docs/qa/`.
- Turns the first `# ` heading into the page title (and removes it from the body), the first
  paragraph into the description, and sets the "Edit page" link to the source file on GitHub.
- Rewrites relative links between docs (`../TROUBLESHOOTING.md#permission-denied`) to site URLs
  (`/docs/troubleshooting/#permission-denied`), and links to any other repository file or folder
  (`../docker/`, `../../LICENSE`, `apps/api/src/...`, excluded notes) to GitHub. Links inside code
  are left alone.
- Copies images that docs reference.
- **Fails** (exit code 1, build stops) when a relative link points at a file that does not exist,
  and lists each one as `file:line target`. Links to a heading that does not exist are printed as
  warnings.

The sidebar is defined in `astro.config.mjs`. Install guides are picked up automatically from
`docs/getting-started/install-*.md`; folders (`using/`, `spec/`, `mobile/`, `qa/`, `legal/`) are
autogenerated; a new root-level doc needs one entry there.

## Privacy and security

No analytics, cookies, third-party scripts, fonts or CDNs: the Chakra Petch heading font is
self-hosted from `@fontsource/chakra-petch`, and search (Pagefind) runs entirely in the browser
from files on this site. `public/_headers` sets the security headers; after the build,
`scripts/csp.mjs` adds the SHA-256 hash of every inline script to the `script-src` directive, so
scripts need no `'unsafe-inline'`.

## Deploying

`.github/workflows/site.yml` builds the site on pull requests that touch `docs/`, `site/` or
`design/brand/` (so a broken doc link fails the PR) and, on pushes to `main` and manual runs,
deploys `dist/` with `wrangler deploy` to the assets-only Worker `arclight-site`
(`wrangler.jsonc`). It needs two repository secrets:

| Secret | Value |
|---|---|
| `CLOUDFLARE_API_TOKEN` | API token with the "Edit Cloudflare Workers" permission for the account |
| `CLOUDFLARE_ACCOUNT_ID` | The Cloudflare account ID |

The custom domain is attached to the Worker once, in the Cloudflare dashboard (Workers & Pages >
arclight-site > Settings > Domains & Routes), or with a `routes` entry with
`"custom_domain": true` in `wrangler.jsonc`. A manual deploy from this folder is
`pnpm build && pnpm deploy:worker`.
